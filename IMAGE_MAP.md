# Image map — Sangati Foundation website

All 41 client images have already been renamed and sorted into folders inside
`public/images/`. Copy that whole folder into your Antigravity project root and
the paths in the prompt will resolve as-is.

**How to read this:** *New filename* is what the file is called now. *Original*
is the WhatsApp filename it came from, so you can trace anything back. *Where it
goes* is the slot on the site.

> Note: filenames are grouped by shape and role (wide files → banners, portrait
> files → posters and cards, highest-resolution files → large feature blocks).
> Before you hand this to the client, open the `programs/` folder and confirm the
> six programme photos match the six programme names — swap any two files if a
> photo fits a different programme better. Everything else is shape-driven and
> will look right wherever it lands.
